About this app

What does this app do in Odoo 20?

Access Management means controlling who can see and do what inside Odoo — menus, apps, models, records, fields, views, buttons, reports, chatter and more. Access Management AI is the all-in-one Odoo 20 access control module that replaces split tools with one no-code workspace for access rights, record rules, security roles, user groups, import/export profiles, audits and AI drafts.

Works on Odoo 20 Community, Enterprise, Odoo.sh and on-premise.

  • Works on Community, Enterprise, Odoo.sh and on-premise
  • No-code access rules instead of custom XML / Python ACL work
  • AI-assisted drafts for faster rule and role drafts
  • Server + UI enforcement for real access security

FAQ

FAQ

What does this app do?

It controls who can see and do what in Odoo — menus, apps, models, records, fields, views, buttons, reports and chatter — with no-code access rights, record rules, security roles and optional AI drafts.

Do I need a developer to use this module?

No. Point-and-click forms cover Rules, Roles, Groups, Mass Assignment, Import/Export and user controls. Optional AI drafts a starting rule/role for review.

Is hiding a menu, button or field real security?

UI hiding is presentation. Use Create / Edit / Delete and record domains for server-enforced boundaries.

What does this module cover compared to split suites?

Menus, models, fields, views, UI elements, reports/actions, search, chatter, schedule, roles, access groups, AI, import/export, audits, dashboard, requests, tags, transfer, password expiry, systray, block apps and more — in one package.

Community and Enterprise?

Yes — Odoo 20 Community and Enterprise on Odoo.sh and on-premise. Third-party Apps Store modules are not available on Odoo Online. Multi-company supported.

Does the module support multiple languages?

Yes. The module uses Odoo’s standard translation system for its menus, views, field labels, buttons, notifications and access-management messages. Translation catalogs are included for Arabic, German, Spanish, French and Simplified Chinese. Install and activate the required languages in Odoo to use them.

Support?

OPL-1 · 90 days free support. Email nexgensolutionsodoo@gmail.com.

What can the AI generator create?

It can draft access rules and reusable security roles from a plain-language description, helping administrators start faster. Review and adjust the result before applying it.

Does AI apply permissions automatically?

No. AI is an assistant, not an approval system. It generates a draft for an administrator to review, edit and explicitly save.

Which AI providers are supported?

The module includes AI workflows for supported configured providers such as Gemini, Claude, OpenAI and Cursor Agent. Availability depends on your configured integration and credentials.

Can I control Create, Edit and Delete separately?

Yes. Model permissions can be configured independently for Create, Edit and Delete, with optional record-domain rules for more precise boundaries.

Can I restrict records by user or condition?

Yes. Define read, write, create and delete behavior with domains, including environment-user conditions and company-specific rules where applicable.

Can I make fields invisible, read-only or required?

Yes. Field rules support invisible, read-only and required behavior, with conditional options and control over relational links and Create / Create & Edit choices.

Which Odoo views can be restricted?

List, Form, Kanban, Calendar, Pivot, Graph, Gantt, Map, Activity and Hierarchy views can be controlled per model and targeted user or group.

Can I hide buttons and notebook tabs?

Yes. Use UI element rules to hide buttons, smart buttons, notebook tabs, field elements and kanban links, with selector and conditional options.

Can I restrict reports and actions?

Yes. Restrict reports plus window, server, client and URL actions, including global controls for Print and Action menus.

Can I control Import, Export and Spreadsheet?

Yes. Import, Export and Spreadsheet actions can be controlled globally or for selected users, models and fields.

Can I hide filters, group-by and search panels?

Yes. Search controls include filters, group-by, favorites, search panels and custom filter or group options.

Can I restrict Chatter?

Yes. Control messages, log notes, activities, followers, attachments and other Chatter capabilities at the level supported by each rule.

What are Security Roles?

Security Roles are reusable permission packages that can be nested, assigned to users or groups, tagged, scheduled and given validity dates.

Can I assign rules to many users at once?

Yes. Mass assignment and Access Groups help apply roles or rules to multiple users, groups and companies efficiently.

Can rules be scheduled?

Yes. Rules can use active dates, daily time windows, timezones and scheduled processing for time-bound access.

Does it support multiple companies?

Yes. Rules and assignments can be scoped to selected companies, helping keep permissions aligned with multi-company operations.

Does it support internal and portal users?

Yes. The module includes controls for internal and portal access scenarios, subject to the Odoo model and security context involved.

What audit information is available?

Review login events, failed logins, access audits, rule activity and related records through the audit views, dashboards and reports.

Can users submit access requests?

Yes. Access Requests provide a workflow for requesting and reviewing permission changes instead of handling every request informally.

Can I make a user read-only?

Yes. Global read-only controls can prevent users from modifying protected data while allowing the access scope you configure.

Can I prevent login or terminate sessions?

Yes. User security includes prevent-login controls and session termination options where supported by the configured security policy.

Can I control developer mode and app management?

Yes. Administrators can disable developer mode for selected users and restrict module installation, upgrade and uninstallation operations.

Can I control systray items?

Yes. Systray visibility can be restricted for supported items such as shortcuts, help and account-related entries.

Can I enforce password expiry?

Yes. Configure password expiry behavior, reminders and related scheduled security actions from the module settings.

Can I move rules between databases?

Yes. Export and import JSON profiles to transfer access-rule configurations between compatible Odoo databases, then review mappings after import.

Does the module include dashboards and PDF reports?

Yes. Use dashboards, pivot and graph analysis, access reports, role reports and request reports to review your security posture.

Will users need to refresh after a rule changes?

Some interface changes take effect after navigation or refresh, while server-side enforcement applies at the relevant request boundary.

Can I test a rule before assigning it broadly?

Yes. Start with a limited user, group or company scope, review the resulting UI and audit behavior, then expand the assignment when verified.

Can existing rules be imported or edited?

Yes. Existing configurations can be reviewed and edited in the rule workspace, and compatible JSON profiles can be imported for further adjustment.

Is the module configurable without XML or Python changes?

Yes. The primary workflows are no-code forms and settings. Technical customization may still be appropriate for unusual business requirements.

What should I do if a restriction does not appear?

Check the rule status, user or group assignment, company scope, dates, priority and target model or view. Review the audit and missing-data logs when available.

Is my data sent to an AI provider?

Only AI workflows configured by your administrator may communicate with an external provider. Review your provider settings, credentials and organization policy before enabling AI features.

What data is sent to the configured AI provider?

When AI generation is used, the module sends the administrator's prompt and the module's access-rule or security-role schema to the selected provider (Google Gemini, Anthropic Claude, OpenAI or Cursor). It does not send Odoo records automatically. Enable the administrator consent setting only after reviewing the selected provider's privacy and retention terms.
